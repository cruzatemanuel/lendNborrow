## 2. Project Overview

**Description:** lendNborrow is a community item-sharing platform where users can list items, browse/search listings, request to borrow items, manage requests, and track borrowed or returned items.

**Objectives**
- [ ] Let users create and manage item listings.
- [ ] Let users browse, search, and view items.
- [ ] Let borrowers submit borrowing requests.
- [ ] Let item owners approve or reject requests.
- [ ] Track borrowing and return statuses.
- [ ] Provide a responsive and usable interface.

## 9. Testing Checklist

### Accounts and permissions
- [ ] Users can register and log in.
- [ ] Invalid credentials are handled appropriately.
- [ ] Users cannot manage listings or requests they do not own.

### Listings
- [ ] Users can create, edit, and remove their own listings.
- [ ] Users can browse, search, and view item details.
- [ ] Unavailable or borrowed items are clearly identified.

### Borrowing workflow
- [ ] Borrowers can submit requests.
- [ ] Owners can approve or reject requests.
- [ ] Status changes display correctly.
- [ ] Invalid or duplicate requests are prevented where applicable.
- [ ] Items can be marked returned and availability updates correctly.

### Usability and reliability
- [ ] Layout works on desktop and mobile-sized screens.
- [ ] Forms show useful validation messages.
- [ ] Empty results and errors are handled.
- [ ] Main workflows have been tested end-to-end.
- [ ] Critical bugs are fixed or documented.
