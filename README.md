# lendNborrow

A web-based platform for lending and borrowing items within a community. Users list items such as books, tools, and equipment, and other users browse what's available and send borrowing requests. The goal is to make resource sharing more convenient, accessible, and organized.

Final project for IT 314 (Web Systems and Technologies), BatStateU Alangilan.

## Objectives

- Let users list items they are willing to lend
- Let users browse and search available items
- Let users send and manage borrowing requests
- Help users track borrowed and returned items
- Encourage resource sharing within the community
