## IT 314 Web System and Technologies

### Web System and Technologies: FINAL PROJECT 2026

## Final Project Guideline

### Overview

For your final project in IT 314 Web Systems and Technologies, you will work in groups to design and develop a fully functional, modern website. Your project should demonstrate your ability to apply web development principles from design to deployment while integrating current technologies and trends.

Your project should reflect real-world relevance and innovation and should align with your academic track

- Business Analytics (BA)

Each project should be designed with user experience, responsiveness, and usability in mind.

#### Website Functionality

- The website must be fully functional, incorporating front-end and back-end components.
- Use HTML, CSS, JavaScript/TypeScript, and appropriate web technologies.
- Develop a backend using Node.js and Express.js to handle the system's data and API.
- Ensure your website is responsive and optimized for multiple devices.
- Include modern web features relevant to your track, such as dashboards, visualizations, reporting, or analytics.

### Evaluation Criteria

Your project will be assessed according to the provided rubrics, which include:

- Website functionality
- Creativity and innovation
- Relevance to academic track
- Design and usability
- Presentation quality
