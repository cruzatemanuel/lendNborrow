## IT 314 Web System and Technologies

### Web System and Technologies: FINAL PROJECT 2026

## Final Project Guideline

### Overview

For your final project in IT 314 Web Systems and Technologies, you will work in groups to design and develop a fully functional, modern website. Your project should demonstrate your ability to apply web development principles from design to deployment while integrating current technologies and trends.

Your project should reflect real-world relevance and innovation and should align with your academic track, such as:

- Network Technology (NT)
- Business Analytics (BA) pick/
- System Management (SM)

Each project should be designed with user experience, responsiveness, and usability in mind.

### Timeline

- **Project Duration:** December 1–5, 2026
- Ensure your website is fully completed and submitted within this timeframe.

### Project Requirements

#### 1. Group Formation

- Each group must consist of **exactly 3 members**.
- Clearly define roles and responsibilities within your group (e.g., developer, designer).

#### 2. Website Functionality

- The website must be fully functional, incorporating front-end and back-end components.
- Use HTML, CSS, JavaScript/TypeScript, and appropriate web technologies.
- Develop a backend using Node.js and Express.js to handle the system's data and API.
- Ensure your website is responsive and optimized for multiple devices.
- Include modern web features relevant to your track, such as dashboards, visualizations, reporting, or analytics.

### Presentation

- Each group will conduct an actual presentation and demonstration of their final project website.
- The presentation should include:
  1. **Group Introduction** – State members' names and roles.
  2. **Project Overview** – Briefly describe your website's purpose and target users.
  3. **Website Functionality** – Show the main pages, features, and layout; highlight responsiveness and user experience.
  4. **Development Process** – Explain how your group designed and developed the website using HTML, CSS, JavaScript, and other tools.

**Details:**

- **Format:** Actual face-to-face presentation and system demonstration
- **Duration:** Maximum of 10 minutes
- **Dress Code:** Formal attire
- **Presentation:** All group members must be present and participate in the presentation.
- **System Demonstration:** The group must demonstrate the actual working system during the presentation.
- **Submission:** Submit the final project folder and required documentation through the designated Google Sheet.

### Submission Details

Fill in all details in the Google Sheet:

- Section workbook
- Group number and members' names
- Topic approval date and submission date
- Project title
- Links to project documentation

**Deadline:** All entries must be completed in the Google Sheet by **December 5, 2026**.

### Evaluation Criteria

Your project will be assessed according to the provided rubrics, which include:

- Website functionality
- Creativity and innovation
- Relevance to academic track
- Design and usability
- Presentation quality
